# Quill

*All your notes in one place*

## How to use?
1. Open the app **Quill**
2. Click on `Make a note`
3. Write your note
4. Click  `Save` when you're done
## Where to find notes?
All notes are divided into **folders**. Before you create your own one, there is a "_General folder_", it is the place where you find your first notes


## What if it doesn't work?
1. Try to reload the app
2. If it doesn't work, reload your device
3. If the problem stays the same -  contact our [support team](https://www.quill.io/support)
