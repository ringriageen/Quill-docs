# Quill

*All your notes in one place*

## How to use?
* Open the app **Quill**
* Click on `make a note`
* Write your note
* Click  `save` when you're done
## Where to find notes?
All notes are divided into **folders**. Before you create your own one, there is a "_General folder_", it's the place where you find your first notes


### What if it doesn't work?
1. Try to reload the app
2. If it doesn't work, reload your device
3. If the problem stays the same -  contact our [support team](www.quill.io/support)
